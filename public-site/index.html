Your progress stays with you.

Saves are stored on this device in this browser, separately for each game mode. They are not uploaded or shared with other players. Use the same Chrome profile and website link to continue.

Clearing site data, using Incognito, or changing devices can lose your progress. You can export your files using the game's folder button.

The first launch downloads a large game package and needs about 1.5 GB of browser storage per mode. Later launches use the installed files. A current desktop Chrome browser is recommended.
