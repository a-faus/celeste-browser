Play Celeste, or mix up the journey with Randomizer. Every player starts fresh.

Play CelestePlay Randomizer

Two modes. One shared save folder.

Normal Celeste and Randomizer save to the same files on this device, in this browser. Close the current game tab before opening the other mode; your saved progress carries over in either direction. Randomizer-only levels still require Randomizer.

Saves are not uploaded or shared with other players. Use the same Chrome profile and website link to continue. Clearing site data, using Incognito, or changing devices can lose your progress. Export important saves using the game's folder button.

Existing separate saves are backed up before migration. If both modes have different versions of the same file, the more recently saved version becomes active.

The first launch downloads a large game package and needs about 1.5 GB of browser storage per mode. Later launches use the installed files. A current desktop Chrome browser is recommended.
